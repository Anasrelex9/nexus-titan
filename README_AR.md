# NEXUS TITAN — النسخة الأولية

## المزايا الحالية
- واجهة عربية مناسبة للهاتف.
- إدخال اسم الفريقين ومعدل الأهداف المتوقع لكل فريق.
- حساب احتمالات تقريبية للفوز والتعادل والخسارة، وأكثر من 2.5 هدف، وتسجيل الفريقين.
- عرض أكثر خمس نتائج دقيقة احتمالاً.
- فحص حالة الخادم عبر `/health`.

## حدود النسخة
هذه نسخة أولية تعليمية تستخدم نموذج Poisson مبسطاً. لا تحتوي على تغذية بيانات مباشرة، ولا تتصل بـ 1xBet، ولا تتعلم تلقائياً من نتائج FC 26. المخرجات احتمالات مشروطة بالمدخلات وليست ضماناً أو نصيحة مراهنة.

## التشغيل
```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```
ثم افتحي `http://localhost:8000`.

## النشر
يحتوي المشروع على Dockerfile ويمكن نشره على خدمة ويب تدعم Docker.
